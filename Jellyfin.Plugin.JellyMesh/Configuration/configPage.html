    Duplicate films

    JellyMesh keeps these titles apart because it cannot be sure they are one film. If they are, select them and merge: the best quality plays, the others stay as backups, a local copy always wins, and watch state moves to the title that stays. Local files are never changed.

    Sync

    Folder

    Absolute path on the server. JellyMesh writes only inside this folder.
    Set by JELLYMESH_FEDERATED_ROOT on the server. To choose it here, remove the variable and restart.

    Metadata

    Locks federated items, so metadata fetchers and "Replace all metadata" leave them alone. When off, fetchers complete the metadata, and titles without provider IDs can be matched to the wrong film.

    Streams

    For the servers connected to this one. A stream with no activity for 2 minutes frees its slot, and this closes its transcode with it. When off, Jellyfin's own timer closes it. A dropped connection closes the transcode either way.

    Advanced playback times

    Most servers can keep these values.
    From 3 to 60. Raise it for a slow remote. A viewer waits this long on each source before the next one is tried.
    From 5 to 60. Raise it if a remote is slow to start a transcode. Opening can take up to three steps on each source.
    From 30 to 109. Lower it to free a remote sooner. A paused player resumes by itself.
    From 1 to 168. After this a paused player has to start the title again.
    From 1 to 60. A change to these rights on the remote takes up to this long to apply here.
